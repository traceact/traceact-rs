# traceact (Rust)

X-ray vision for your code: lightweight, action-level tracing.

This crate is a placeholder reserving the `traceact` name on crates.io while the
Rust port is in progress. It has no usable API yet.

Today, TraceAct ships as a Python package: <https://pypi.org/project/traceact>.
The Rust port will follow the same model — record what your code did as
structured traces, then read them back — with a Rust-native API.
